## 正期望公式

```
正期望 = 胜率 × 平均盈利 - (1-胜率) × 平均亏损

示例：
- 胜率40%，盈亏比3:1 → 0.4×3 - 0.6×1 = +0.6（正期望）
- 胜率50%，盈亏比1.12 → 0.5×1.12 - 0.5×1 = +0.06（正期望）
```

**地球仪实战数据**：胜率50% + 盈亏比1.12 = 年化20%，七年连续盈利

## 可立即测试的策略

### P0: 多周期K线法 ❌ 已验证失效

**A股适配（简化版仅用日线）**：
- 日线：定方向（高点低点同步抬高/降低）
- 日线：找支撑阻力区域（最近10日最高最低）
- 日线：进场信号（突破前日高点+成交量>1.5倍均值）
- 止损：突破点下方3%，止盈：突破点上方8%（盈亏比2.6）

**2023-2024回测结果**：
| 指标 | 结果 | 对比基准 |
|------|------|----------|
| 年化收益 | **-67.11%** | ❌ 远低于基准 |
| 最大回撤 | **-91.85%** | ❌ 灾难级回撤 |
| 胜率 | **23.7%** | ❌ 低于50%标准 |
| 盈亏比 | **2.29** | ✅ 理论可行但实际失败 |
| 止损次数 | **90次** | ❌ 过多止损 |
| 止盈次数 | **28次** | ❌ 止盈太少 |

**失效原因分析**：
1. 趋势判断滞后（高点低点同步抬高太慢）
2. 突破信号在震荡市频繁失败
3. 3%止损太紧，容易被反复扫损

**结论**：知乎"多周期K线策略"在A股震荡市环境下完全失效，与均线趋势过滤策略（-35.56%）一致。**不建议使用**。
