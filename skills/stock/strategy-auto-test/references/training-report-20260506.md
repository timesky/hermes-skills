## 技术发现

### 财务数据问题
- **症状**: 因子策略显示 0% 收益
- **原因**: financial_cache 加载失败，financial_data = {}
- **影响**: 基于财务因子的策略无法筛选股票
- **解决**: 先运行 financial_cache.py，或使用纯技术指标策略

### 策略指纹生成
```python
def generate_fingerprint(strategy_type, params):
    sorted_params = sorted(params.items())
    param_str = f"{strategy_type}:" + ",".join([f"{k}={v}" for k, v in sorted_params])
    return hashlib.md5(param_str.encode()).hexdigest()[:16]
```
