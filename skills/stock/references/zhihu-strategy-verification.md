# 知乎策略验证方法论

## 背景

知乎策略文章常为营销性质，结尾推销AI自动化工具、付费课程等。需验证实际效果。

## 验证方法

### 1. 评论区回测验证

高赞评论中常有量化用户自发回测：

| 验证维度 | 检查方法 |
|----------|----------|
| 实际胜率 | 评论区搜索"回测"、"胜率"、"验证"关键词 |
| 测试样本 | 记录测试股票数量、时间范围 |
| 验证者身份 | 量化从业者评论可信度更高 |

### 2. 典型案例（2026-05-10）

| 策略 | 原声称 | 实际验证 | 来源 |
|------|--------|----------|------|
| MACD+RSI+MA组合 | 88%胜率 | 31.9%胜率（19只A股回测） | 评论区-工程人的量化笔记 |
| 平均收益 | 未提及 | +20.5%（中位数-7.5%） | 同上 |

**验证者详细数据**：
- 测试股票：19只随机A股
- 交易次数：502次
- 盈利占比：47%
- 结论："88%胜率纯属营销话术"

### 3. 注册表记录格式

```json
{
  "verified": false,
  "verification_note": "评论区回测验证：声称88%胜率实际31.9%，为营销文章卖软件，谨慎参考",
  "backtest_verified": {
    "claimed_win_rate": 88.0,
    "actual_win_rate": 31.9,
    "verifier": "知乎用户-工程人的量化笔记"
  }
}
```

## 验证优先级

| 信号 | 优先级 | 说明 |
|------|--------|------|
| 评论区量化用户回测 | ⭐⭐⭐ 最高 | 有具体数据支撑 |
| 文章自带回测图表 | ⭐⭐ 中 | 可能选择性展示 |
| 无验证数据 | ⭐ 低 | 仅记录逻辑，待回测 |

## 营销文章特征识别

1. 结尾推销"AI自动化炒股工具"、"付费课程"
2. 赞数高但评论少（刷赞嫌疑）
3. 赞数高但评论区有质疑（典型营销模式）
4. 实际胜率远低于声称值（差距>20%）

## 后续处理

- `verified: false` 的策略需独立回测验证
- 记录来源URL供追溯
- 不直接用于实盘建议
