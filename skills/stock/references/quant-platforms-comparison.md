## 一、平台分类总览

| 分类 | 平台 | 实盘支持 | 免费额度 | 资金门槛 |

## 二、券商量化终端（支持实盘）

### QMT（迅投）

| 特点 | 说明 |
|------|------|
| **运行环境** | 本地运行，策略代码存在自己电脑 |
| **编程语言** | Python + VBA |
| **支持品种** | 股票、两融、期货、期权、ETF、可转债、港股通、美股 |
| **数据** | 5m/1m全部，tick 2018至今，含Level2 |
| **Mini模式** | 可接外部IDE（PyCharm/VS Code），灵活度高 |
| **交易速度** | LDP极速柜台 + VIP席位，微秒级 |
| **资金门槛** | 原本30-50万，现已降至~10万（部分券商渠道） |

**适合人群**：
- 有编程基础（Python/VBA）
- 做高频交易、多品种策略
- 对策略隐私性要求高

### PTrade（恒生）

| 特点 | 说明 |
|------|------|
| **运行环境** | 云端运行，关机也可跑策略 |
| **编程语言** | Python（接口类似聚宽，新手友好） |
| **支持品种** | 股票、两融、ETF、可转债（无期货/期权） |
| **数据** | 含Level2数据 |
| **自动化工具** | 条件单、拐点交易、抢单交易等 |
| **资金门槛** | 同QMT，~10万 |

**适合人群**：
- 新手入门、中低频交易
- 希望策略24小时云端运行
- 主要做股票、可转债

## 四、模拟实盘（Paper Trading）对比

> **核心区别**：模拟实盘 ≠ 真实实盘
> - 模拟实盘 = 虚拟资金模拟交易
> - 真实实盘 = 真金白银交易

### 各平台模拟实盘限制

| 平台 | 模拟实盘功能 | 免费额度 | 实时性 | 关键限制 |
|------|-------------|---------|--------|----------|
| **聚宽** | ✅ 有 | 永久位可用 | ⚠️ **延时运行** | 普通用户收盘后才跑，次日凌晨3点更新 |
| **米筐** | ✅ 有 | 基础功能 | ⚠️ 未知 | 已取消实盘功能 |
| **掘金量化** | ✅ 有 | 本地运行 | ✅ **实时** | 需自己部署 |
| **同花顺Supermind** | ✅ 有 | 有限制 | ✅ 实时 | 实盘个数限制 |
| **宽邦** | ✅ 有 | **个数无限制** | ✅ 实时 | 实盘需付费 |
| **天勤量化** | ✅ 有 | **完全免费** | ✅ **实时** | 仅支持期货 |
| **QMT/PTrade** | ✅ 有 | 软件免费 | ✅ 实时 | 需开户+资金门槛 |

### 聚宽模拟实盘详情

| 用户等级 | 运行方式 | 说明 |
|----------|----------|------|
| 普通用户 | 延时运行 | 收盘后才执行策略，次日凌晨3点后更新结果 |
| VIP/SVIP | 实时运行 | 交易时间正常执行 |
| 积分兑换 | 限时实时 | 积分兑换限时位，到期后关闭 |

**结论**：聚宽免费用户的模拟实盘不是真正的实时盘，只能事后验证策略。

## 五、QMT/PTrade开通流程

### 步骤

1. **选择券商**：推荐国金证券（门槛最低，~10万）
2. **开户入金**：完成开户并达到资金门槛
3. **提交申请**：入金后第二天提交QMT/PTrade申请
4. **等待开通**：约2个工作日
5. **获取测试账号**：开通期间可先拿测试账号练习回测
6. **软件下载**：开通后邮件发送下载地址
7. **开始使用**：登录软件，编写策略，实盘运行

## 七、关键结论

1. **"烧钱时代"已过去**：聚宽、米筐等老牌平台已取消免费实盘
2. **实盘必走券商终端**：QMT/PTrade是目前唯一免费实盘路径
3. **门槛已降低**：从30-50万降至~10万（部分券商渠道）
4. **本地化是终局**：掌握Backtrader+AkShare，不被平台卡脖子
