# 五日不破策略详解

> 来源：知乎专栏 - "五日不破，不必操作"
> 回测脚本：`scripts/five_day_hold_strategy.py`

## 策略核心逻辑

### 定义
- **五日**：5日均线（5个交易日收盘价平均值）
- **五日不破**：收盘价不跌破5日均线（盘中跌破不算）
- **有效跌破**：收盘跌破 + 次日收盘仍无法收回
- **不必操作**：趋势未变时，不卖出、不加仓、不换股

### 选股标准

#### 排除项
| 类型 | 理由 |
|------|------|
| 连续亏损股 | 防业绩暴雷 |
| ST/*ST | 有退市风险 |
| 短期暴涨妖股 | 纯资金炒作 |
| 小盘股(<30亿) | 易被控盘，信号失真 |

#### 选择标准
| 条件 | 要求 |
|------|------|
| 中期趋势 | 站稳60日均线 |
| 5日线方向 | 向上发散 |
| 成交量 | 温和配合 |
| 市值 | 50-500亿 |

### 操作流程

| 步骤 | 规则 |
|------|------|
| **建仓** | 收盘站稳5日线 → 次日开盘买入3成仓位 |
| **加仓** | 连续2日站稳5日线 → 加仓3成（总6成） |
| **持仓** | 收盘不破5日线 → 坚持不动 |
| **卖出** | 有效跌破5日线 → 开盘清仓 |
| **止损** | 买入后直接跌破 → 控制在10%内 |

## 策略分析

### ✅ 优势
1. **简单易执行**：单一指标，无复杂计算
2. **顺势而为**：抓住上涨趋势中段
3. **减少错误**：低频交易，降低犯错概率
4. **心态友好**：不盯盘、不被波动干扰
5. **盈亏比高**：平均盈亏比 1.13~3.18，符合"小亏大赚"原则

### ⚠️ 局限性
1. **震荡市失效**：5日线反复穿越时频繁止损
2. **滞后性**：均线本身有滞后，卖出时已回调一定幅度
3. **单边下跌无防护**：买入后直接下跌，止损可能来不及
4. **股票依赖性强**：选股是关键
5. **不适用于所有股票**：需严格选股

- ❌ 妖股、小盘股（<30亿）

## 无未来函数执行要点

> **核心原则**：所有决策基于已收盘数据，不依赖当日盘中或未来信息

### 入场信号确认（收盘后判断）

| 条件 | 判断依据 | 备注 |
|------|----------|------|
| 今日收盘 > 今日MA5 | 基于今日收盘价计算 | ✓ 可用 |
| 昨日收盘 > 昨日MA5 | 基于昨日收盘价计算 | ✓ 可用 |
| 今日阳线（收>开） | 基于今日数据 | ✓ 可用 |

**正确执行**：收盘后判断 → 次日开盘操作

### 常见执行错误

| 错误类型 | 表现 | 后果 | 案例 |
|----------|------|------|------|
| **追高买入** | 跳空高开日买入，收盘已跌破MA5 | 当日被套 | 跳空7%买入，收盘跌破MA5 |
| **抄底失败** | 连续跌破MA5时"抄底" | 接飞刀 | 连续2日跌破MA5后买入 |
| **信号不足** | 仅1日站上MA5就买入 | 假突破 | 需确认连续2日站稳 |
| **跳空误判** | 开盘价远高于昨日收盘 | 实际已背离MA5 | 开盘看涨，实际背离 |

### 交易复盘分析流程

```bash
# 1. 获取历史K线数据
# 2. 计算MA5、MA10、MA20
# 3. 对每个交易日期：
#    - 检查当日收盘 vs 当日MA5
#    - 检查昨日收盘 vs 昨日MA5
#    - 判断是否符合策略信号
# 4. 总结：哪些交易违反策略规则
```

### 实战案例分析

**案例：600584 长电科技**

| 交易日期 | 操作 | 价格 | MA5状态 | 判定 |
|----------|------|------|---------|------|
| 01-19 | 买入 | 49.16 | 连续2日站上 | ✓ 符合 |
| 01-22 | 买入 | 51.16 | 当日跌破 | ✗ 追高 |
| 03-03 | 卖出 | 49.80 | 跌破MA5 | ✓ 合理止损 |
| 03-09 | 买入 | 45.63 | 连续2日跌破 | ✗ 抄底 |

**教训**：
1. 跳空高开日需等收盘确认，不能开盘追入
2. 跌破MA5后不抄底，等MA5拐头向上再入场
3. 连续2日站上MA5才是有效信号
