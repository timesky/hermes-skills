# 热门板块优先选股策略

## 核心发现

热门板块股票**不适合底部反转策略**，必须使用趋势跟随策略。

### 问题背景

原选股逻辑：全市场扫描 → 寻找震荡区间底部 → 添加热门板块加分

**失败原因**：
- 热门板块今日涨幅最大（+5%~+7%）
- 成分股正处于上涨过程中，不在"底部"
- 底部反转策略筛选失败 → 0只候选

### 解决方案：双策略架构

```
┌─────────────────────────────────────────────────────────────┐
│ 热门板块成分股                                                │
│   ↓                                                         │
│ 趋势跟随策略（动量、均线多头、放量）                            │
│   ↓                                                         │
│ 得分 + 热门板块权重（TOP1:50分, TOP2-3:40分, TOP4-5:30分）     │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 全市场股票（非热门板块）                                       │
│   ↓                                                         │
│ 底部反转策略（RSI超卖、震荡底部、回调买入）                     │
│   ↓                                                         │
│ 基础得分                                                     │
└─────────────────────────────────────────────────────────────┘
```

## 趋势跟随策略评分规则

| 条件 | 得分 | 说明 |
|------|------|------|
| 均线多头排列（MA5 > MA10 > MA20） | +30 | 趋势向上 |
| RSI适中（40-70） | +20 | 非超买 |
| RSI偏低（30-40） | +25 | 接近超卖，反弹空间 |
| 价格站上MA5 | +15 | 短期强势 |
| 近期放量（量比>1.3） | +15 | 有资金关注 |
| 5日涨幅0%-8% | +10 | 适中涨幅 |
| 5日涨幅≥8% | -10 | 涨幅过大，减分 |

## Pitfalls

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 热门板块候选为0 | 用底部反转策略评估上涨股票 | 改用趋势跟随策略 |
| API频率限制 | 获取板块成分股时请求过多 | 每只股票间隔0.05秒 |
| 科创板股票选入 | 用户无法交易（50万门槛） | 可选：排除688开头代码 |

