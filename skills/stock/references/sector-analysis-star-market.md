# 板块分析与科创板跟踪

## 一、板块预测验证工作流

### 场景
用户有中长期板块预期（如半导体、CPO、商业航天），需要对比实际市场表现验证判断。

### 工作流程

```
1. 获取当日板块排行数据
   └─→ AkShare: stock_board_industry_name_em()
   └─→ 返回496个板块涨跌幅排名

2. 映射用户预期板块到实际板块
   └─→ 关键词匹配（如"CPO" → "通信线缆及配套"、"通信设备"）
   └─→ 示例映射表：
       | 用户预期 | 实际板块关键词 |
       |----------|---------------|
       | 半导体 | ["半导体", "芯片", "集成电路", "PCB", "元件"] |
       | 光模块/CPO | ["光通信", "通信设备", "通信线缆", "光纤"] |
       | 商业航天 | ["航天", "军工", "国防", "飞机制造"] |

3. 对比分析
   └─→ 检查预期板块在今日排行中的位置
   └─→ 计算准确度（命中率）
   └─→ 识别偏差原因（政策热点、市场主线差异）

4. 输出报告
   └─→ 保存路径: ~/.hermes/profiles/stock/knowledge/raw/{topic}_{date}.md
   └─→ 推送飞书: send_message(target="feishu")
```

### Python代码模板

```python
import akshare as ak
import pandas as pd

# 获取板块排行
df_board = ak.stock_board_industry_name_em()

# 定义预期板块关键词映射
keywords = {
    "半导体": ["半导体", "芯片", "集成电路", "PCB", "元件"],
    "光模块/CPO": ["光通信", "通信设备", "通信线缆", "光纤"],
    "商业航天": ["航天", "军工", "国防", "飞机制造"],
}

# 搜索匹配
for sector, terms in keywords.items():
    print(f"\n{sector}相关板块：")
    for term in terms:
        matches = df_board[df_board['板块名称'].str.contains(term, na=False)]
        if len(matches) > 0:
            for _, row in matches.head(3).iterrows():
                print(f"  ✅ {row['板块名称']}: {row['涨跌幅']:+.2f}% (排名{row['排名']})")
```

### 验证标准

| 准确度 | 评判标准 |
|--------|----------|
| ⭐⭐⭐⭐⭐ | 预期板块在TOP10内，涨幅>3% |
| ⭐⭐⭐⭐ | 预期板块在TOP50内，涨幅>1% |
| ⭐⭐⭐ | 预期板块在榜单内，涨幅>0 |
| ⭐⭐ | 预期板块未上榜，但相关板块上榜 |
| ⭐ | 预期板块及相关板块均未上榜 |

## 四、常见问题

### Q: 板块关键词匹配失败怎么办？

**原因**：板块命名不统一（如"CPO"无直接对应板块）

**解决**：
1. 查看完整板块列表（496个）
2. 使用相关关键词（"通信"、"光"）
3. 查看具体股票所属板块（个股 → 板块映射）

```python
# 查看个股所属板块
df_stocks = ak.stock_individual_info_em(symbol="300308")  # 中际旭创
print(df_stocks)  # 查看所属行业
```

### Q: 科创板指数数据获取失败？

**AkShare接口**：
- `stock_zh_index_daily_em(symbol="科创50")` — 历史数据
- `stock_zh_index_spot_sina()` — 实时数据（可能失败）

**备选方案**：
- 东方财富网直接查询
- 同花顺APP查看
