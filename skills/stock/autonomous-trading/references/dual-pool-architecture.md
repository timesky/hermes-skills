# 动态双池架构详解

## 设计理念

**问题**：固定股票列表不是真正的实盘模拟，只是对固定股票做预测。

**解决方案**：双池动态架构
- **选股池**：每日从全市场筛选买入候选
- **持股池**：从模拟账户持仓检测卖出信号

---

## 选股池生成逻辑

### 市场阶段 → 选股策略

| 阶段 | 选股策略 | 核心条件 |
|------|----------|----------|
| **熊市** | RSI超卖反弹 | RSI<30，加分项：(30-RSI)×3 |
| **牛市** | 回调买入 | 从20日高点回调3%-10%，MA20支撑 |
| **震荡** | 网格策略底部 | 震荡区间5%-15%，价格在底部30% |

### 通用加分项

```python
# 成交量放大
vol_ratio = recent_volume / avg_volume
if vol_ratio > 1.5:
    score += 10  # 量比放大加分

# 均线多头排列
if ma5 > ma10 > ma20:
    score += 15  # 均线多头加分
```

## 持股池卖出检测逻辑

### 卖出信号类型

| 信号 | 触发条件 | 建议卖出价 |
|------|----------|-----------|
| **止损** | 盈亏 ≤ -10% | 当前价 × 0.98 |
| **止盈** | 盈亏 ≥ +20% | 当前价 × 1.01 |
| **策略反转** | RSI>70 或 MA5死叉MA10 | 当前价 × 0.99 |
| **时间止盈** | 持仓>30天 且 盈亏>5% | 当前价 × 1.01 |

## 每日流程时序

```
15:15 收盘后运行
├── Step 1: 验证昨日预测（准确度评分）
├── Step 2: 反思微调（准确度<60分触发）
├── Step 3: 更新持仓市值
├── Step 4: 持股池检测（卖出信号）
├── Step 5: 选股池扫描（买入候选）
├── Step 6: 生成次日预测
│   └── 预测池 = sell_pool + buy_pool[:5] + hold_positions
├── Step 7: 执行卖出交易
├── Step 8: 执行买入交易（buy_pool前2名）
└── Step 9: 生成预测报告 + 推送飞书
```

## 关键脚本代码片段

### 选股池生成核心逻辑

```python
# 震荡市选股（网格策略）
for symbol in all_stocks:
    # 震荡区间5%-15%
    range_pct = (high_30d - low_30d) / low_30d
    if range_pct < 0.05 or range_pct > 0.15:
        continue
    
    # 当前价格在底部30%
    price_position = (current_price - low_30d) / (high_30d - low_30d)
    if price_position < 0.35:
        score = (1 - price_position) * 50
        candidates.append((symbol, score))
```

### 卖出信号检测核心逻辑

```python
# 止损检查
if pnl_pct <= -0.10:
    sell_signal = "止损"
    suggested_price = current_price * 0.98

# 策略反转检查（RSI超买）
if current_rsi > 70:
    sell_signal = "策略反转"
    suggested_price = current_price * 0.99
```

## 最佳实践

1. **先检查卖出，后检查买入** - 持股优先处理
2. **买入控制前2名** - 资金限制，避免过度分散
3. **预测仅对有操作意图的股票** - 不要预测全市场
4. **每季度增量更新财务数据** - 选股池需要最新财务指标
