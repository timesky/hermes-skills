# 组合策略测试系统

## 触发条件
- 用户要求测试不同市场阶段的策略组合
- 用户提出熊市波段、逆向建仓思路
- 用户要求"不同走势都能盈利"或"熊市也有波段"

## 核心思路（用户指导）

### 逆向思维
- **大趋势不坏**：价格 >= MA60 × 95%（或趋势强度 > -0.5）
- **硬逻辑支撑**：ROE > 10% 或 销售净利率 > 8%
- **逢低分批吸纳**：每跌3%加仓一批（最多3批）
- **逢高分批出货**：每涨8%减仓30%，涨15%减仓50%

### 板块筛选
- **政策扶持板块**：AI算力、新能源、半导体、军工、医药
- **真实相关个股**：业绩支撑（ROE/净利率达标），非蹭概念
- **熊市选防御板块**：医药、军工
- **牛市选进攻板块**：AI算力、半导体、新能源

## 关键发现（试错总结）

### 1. 分批建仓逻辑
- **问题**：分批买入0次（建仓逻辑有bug）
- **原因**：调仓时一次性建满，没有加仓空间
- **解决**：熊市只建50%，后续每周检查加仓

```python
# 熊市建仓：先建50%
target_position_ratio = strategy_config['position_ratio']
if phase == 'bear' and strategy_config.get('batch_buy'):
    target_position_ratio *= 0.5

# 后续每周检查
if current_value < target_value * 0.8:  # 未满80%仓位
    if trend_ok and drawdown <= -0.03:  # 趋势不坏+跌3%
        # 加仓
```

### 2. 熊市选股筛选
- **问题**：ROE>12%+净利率>10%筛选太严，选不出股票
- **解决**：放宽到ROE>10%或净利率>8%

```python
if phase == 'bear':
    if not (has_hard_logic or trend_ok):  # 或关系（放宽）
        continue
    if not (fin.get('roe', 0) > 10 or fin.get('net_margin', 0) > 8):
        continue
```

### 3. 熊市止损策略
- **问题**：熊市不主动止损→回撤恶化（-15.75%）
- **解决**：保留止损但放宽到-20%

```python
'bear': {
    'stop_loss': -0.20,  # 放宽止损（熊市波动大）
}
```

## 风控体系（硬指标）

### 三层防护架构

```
┌─────────────────────────────────────────┐
│  第一层：单只止损 -5%（硬指标）          │
│  → 保护单股风险敞口                      │
│  → 触发即卖出，无条件执行                │
└─────────────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────┐
│  第二层：组合止损 -10%（硬指标）         │
│  → 保护整体资金安全                      │
│  → 触发即清仓，保留现金                  │
└─────────────────────────────────────────┘
                   ↓
┌─────────────────────────────────────────┐
│  第三层：仓位控制 30%/70%（硬指标）      │
│  → 分散风险，保留现金                    │
│  → 极端行情下保留翻身资本                │
└─────────────────────────────────────────┘
```

**重要警示（2015股灾测试）**：
- 千股跌停时止损失效，亏损可达-33%～-58%
- 流动性危机是最大风险，无法卖出时只能被动持有
- **组合止损-10%是最后防线**，触发即清仓

## 极端压力测试

### 2015股灾测试结果（2026-05-04）

**测试场景**：上证指数 5178→2850（-45%）

| 场景 | V5低波动 | 进攻策略 | V3波段 |
|------|---------|---------|--------|
| 正常暴跌 | -2.50%（止损有效） | -3.50%（止损有效） | -5.60%（止损有效） |
| 千股跌停 | ⚠️ -33.38%（止损失效） | ⚠️ -58.02%（止损失效） | ⚠️ -41.60%（止损失效） |
| 停牌潮 | ⚠️ -33.38%（止损失效） | ⚠️ -58.02%（止损失效） | ⚠️ -41.60%（止损失效） |

**关键发现**：
1. **流动性危机是致命风险**：千股跌停、停牌潮时止损机制完全失效
2. **单只止损-10%过宽**：极端情况下被动持有，亏损放大至30%～60%
3. **组合止损缺失**：无整体风险控制，可能在极端行情中爆仓

**极端行情应对**：
- 阶段1（风险预警）：指数连续3天下跌>5% → 减仓至30%
- 阶段2（流动性枯竭）：千股跌停 → 接受损失，等待反弹
- 阶段3（停牌潮）：复盘后第一时间卖出
