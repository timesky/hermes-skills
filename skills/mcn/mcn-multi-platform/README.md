# 多平台内容发布脚本使用说明

## 快速开始

### 基本用法

```bash
python publish-all.py <article_path>
```

### 示例

```bash
# 发布到所有平台
python publish-all.py /path/to/article.md

# 仅发布到知乎和掘金
python publish-all.py /path/to/article.md zhihu,juejin
```

## 支持的平台

| 平台 | 内容类型 | 发布延迟 | 特点 |
|------|---------|---------|------|
| 知乎 | 问答型/深度分析 | 即时 | 疑问式标题，需引言 |
| 掘金 | 技术干货/教程 | 1小时后 | 技术标签前缀 |
| CSDN | 教程/工具推荐 | 2小时后 | SEO优化关键词 |
| 头条号 | 大众科技/热点解读 | 即时 | 情绪词标题 |

## 标题适配规则

### 知乎
- 原标题: "全球芯片巨头集体暴涨背后"
- 适配后: "全球芯片巨头集体暴涨背后，发生了什么？"

### 掘金
- 原标题: "AI生成毒大米事件解析"
- 适配后: "[AI] AI生成毒大米事件解析"

### CSDN
- 原标题: "英伟达股价创新高"
- 适配后: "英伟达股价创新高_人工智能_投资"

### 头条号
- 原标题: "芯片股票大涨"
- 适配后: "刚刚，芯片股票大涨"

## 输出文件

执行后会在文章目录下创建 `multi_platform/` 文件夹：

```
article.md
multi_platform/
  ├── zhihu_20260507_223000.md
  ├── juejin_20260507_223000.md
  ├── csdn_20260507_223000.md
  ├── toutiao_20260507_223000.md
  └── publish_plan.json
```

## 发布计划 (publish_plan.json)

```json
{
  "article": "article.md",
  "created_at": "2026-05-07T22:30:00",
  "platforms": {
    "zhihu": {
      "status": "adapted",
      "adapted_title": "...",
      "delay_hours": 0
    },
    ...
  }
}
```

## 手动发布流程

1. 查看生成的适配文件
2. 根据发布计划中的延迟时间
3. 登录各平台手动发布
4. 记录发布链接到发布计划
